# React Native and TypeScript study materials

Open **index.html** in a browser. The study hub starts with five connected skills: arrow functions, map and lists, immutable array state, callback props, and TypeScript inference. Choose any skill and switch freely between **Understand**, **Example**, **Try it**, and **Self-check**.

The examples highlight one part of the code at a time. Scratchpads save your attempts locally, hints and answers stay closed until you open them, and self-checks explain the reasoning behind each answer. These controls are available without an account or a server.

## Explore in your own order

- **Concepts:** twelve illustrated lessons, with a chapter picker and links to matching exercises.
- **Visual labs:** six interactive demonstrations of returns, state queues, callback flow, layout, effects, and Promises.
- **Practice:** sixteen coding exercises with search, hints, worked answers, and ways to test your work.
- **Mock interviews:** three original scenarios and twenty-four questions. Timing, pacing, and scoring are optional.
- **Cheat sheet:** a searchable-from-the-hub reference with a pattern picker and direct links from each core skill.

The hub searches across lessons, exercises, labs, and questions. Your chosen skill, learning view, reading size, and notes stay in this browser when storage is available. The Reading size control offers Comfortable and Large text. Topic tabs support arrow keys, Home, and End; the mobile view uses a native skill selector.

## Printable and offline copies

The **Concept guide**, **Practice workbook**, and **Cheat sheet** are available as both PDF and editable Word files in `downloads`. The concept guide begins with an overview and contents; its detailed six-hour schedule is an optional appendix. The workbook invites you to choose exercises by skill. Durations are estimates, not deadlines.

For learners who prefer a timetable, open **Want more structure?** near the bottom of the hub. It retains the editable day planner, class times, and the separate two-page `six-hour-plan.pdf` and Word document. You can use every lesson and exercise independently of that schedule.

The complete ZIP includes the site, documents, and `practice/MenuApp.tsx`. Keep the HTML pages and assets directory together after extracting it. Modern browsers can open `index.html` directly. External sources and course demo links need internet access. Private browsing or some file viewers may not preserve local notes.

The browser labs illustrate concepts, and the scratchpads save text; they do not compile or run React Native. Use the course development environment for real TSX practice. Example app instructions are in `practice/README.md`.

## Scope and review

The materials cover technical topics in all ten supplied Autumn 2026 lecture decks and use thirty official online references. Later topics outside those decks are distinguished from the core material. These are independently prepared materials, not an official assessment or rubric.

Separate reviewers checked the teaching content, navigation, responsive layouts, keyboard behavior, and document pagination. See `review/04-ux-review.md` for the latest review and `review/03-final-validation.md` for the earlier content and code verification. Screen-reader behavior and native-device execution have not been directly tested.
